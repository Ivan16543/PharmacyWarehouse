Информационная система «Аптечный склад»
В данном репозитории будут собраны лабораторные работы по ПнаЯВУ, реализующие объектно-ориентированную модель аптечного склада на языке C++, позволяющую управлять хранением лекарственных препаратов, контролировать сроки годности и учитывать требования к условиям хранения.

Вариант 25. Аптечный склад
Описание предметной области
Аптечный склад хранит лекарственные препараты различных категорий:

Препараты: имеют название, производителя, серию, срок годности и количество упаковок.

Категории препаратов: определяют дополнительные требования к условиям хранения (температурный режим).

Склад: ведёт учёт всех партий препаратов, контролирует их наличие и не допускает выдачу просроченных позиций.

Процесс учёта и контроля:
Каждый препарат относится к определённой категории (обычный, рецептурный и т.д.).

Для каждой категории задаются допустимые условия хранения (например, температурный диапазон).

Препараты принимаются на склад и выдаются со склада.

Система проверяет срок годности перед выдачей и блокирует операции с просроченными партиями.

Просроченные препараты подлежат утилизации.

Функционал программы
Создание и управление структурой (добавление препаратов на склад, поиск по названию).

Приём и выдача препаратов (изменение количества упаковок).

Контроль сроков годности (проверка просрочки, утилизация просроченных партий).

Контроль условий хранения (проверка допустимой температуры для категории препарата).

Учёт наличия (вывод полного отчёта по складу, фильтрация по годности).

Архитектура проекта (Классы)
Проект спроектирован с использованием ООП и включает следующие ключевые классы:

Класс	Назначение
PharmacyWarehouse	Главный управляющий класс — содержит коллекцию препаратов, управляет приёмом, выдачей и утилизацией
Medicine	Препарат — хранит название, производителя, серию, срок годности, количество упаковок, категорию и температуру хранения

Сборка и запуск
Требования
Компилятор с поддержкой стандарта C++11 или выше (GCC / Clang / MSVC).

Установленная утилита make или настроенный VS Code.


Компиляция через терминал
g++ -std=c++17 -Wall -Wextra main.cpp Medicine.cpp PharmacyWarehouse.cpp -o pharmacy
Запуск
./pharmacy
